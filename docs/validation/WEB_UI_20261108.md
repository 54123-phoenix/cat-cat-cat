# Web 界面与交互优化（2026-11-08）

用户选择先优化 Web，保留橙色校园风格。本轮只修改 Web 展示与交互、验证和文档；未操作业务数据库、部署服务器或更改识别默认策略。此前的明确提交、请求幂等、待审可见性继续保留。

## 已完成

- **首页**：照片和拍照入口优先；移除重复主操作及容易被误认为总量的数字，辅助任务和抽签可展开。用“最近的校园偶遇”替代未经定位支持的“附近”，各数据源独立加载、失败可重试并保留已有内容。
- **图鉴**：搜索可清除、筛选可重置并播报结果数；请求失败不会显示为零进度或“未相遇”。筛选有选中语义、未知状态及足够触控面积。原稀有算法保留，明确标为趣味规则。
- **识猫**：先选照片、后识别，再核对提交；只显示一张照片和一处相似度。上传支持键盘，识别结果、提交失败及回执接收焦点；地点始终可见，可选信息折叠，输入有标签和字数提示。长猫名在窄屏正常换行。
- **导航与地图**：桌面使用常驻侧栏，移动端保留五项底部导航，补齐安全区、选中和焦点状态。菜单关闭时不可被键盘访问，打开后循环焦点，Escape 关闭并还原焦点。地图被约束在主栏内，定位提示和工具不覆盖侧栏；地图不可用时引导浏览图鉴和记录偶遇，不向普通用户展示申请开发者 Key 的步骤。
- **共用细节**：按钮最小 44px、核心说明文字 14px；主色及语义色加深以改善对比度，Logo 保留原橙色。通知最多显示三条，可关闭，悬停/聚焦/后台页暂停计时；空态可操作，子页标题不再与主栏双重吸顶。
- **加载**：移除阻塞样式加载的远程字体导入，保留本地字体栈；辅助弹卡按需加载并用局部 Suspense，避免加载时替换整个页面。主入口 JS 从本轮第一次构建的 505.77 kB 降至 495.70 kB（gzip 147.51 → 145.03 kB），这是打包体积变化，不是实测网速结论。
