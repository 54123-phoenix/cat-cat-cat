# 远端 CI 复验与修复

日期：2026-11-01。基线提交 `45dbc138f73d2217cb31705bc00b213c6cedbef5`。

## 已复现的问题

[首次远端运行](https://github.com/54123-phoenix/cat-cat-cat/actions/runs/41164701382) 中，Web、小程序、真实 Redis 三个任务通过；后端与参考库浏览器任务失败。核心浏览器六组已通过，不能把整个 browser-smoke 任务记为通过。

1. **测试密码依赖运行环境。** CI 设置 `ADMIN_PASSWORD=ci-admin-pass`，三个 API 测试模块用 `setdefault` 配置另一个密码并写死登录密码。应用 lifespan 按实际配置创建账号，测试中的补建账号逻辑不会覆盖已有账号，因而登录返回 401。远端结果为 228 passed、1 failed、9 errors；本地使用同样环境复现 33 passed、1 failed、9 errors。修复在隔离夹具的上下文中设置测试专用密码并自动恢复，测试共享常量，移除重复插入账号的逻辑；生产初始化逻辑不变。
2. **页面轮询与断言超时竞争。** 页面每 5 秒轮询，`page.set_default_timeout(20000)` 并不改变 Playwright `expect` 默认的 5 秒超时。远端 trace 显示任务于 03:32:49 UTC 入队、03:32:50 进入 running，03:32:54 的自动请求已经返回 running，页面断言仍在渲染完成前到期。修复先在 20 秒内核对 worker 存活及 API 任务状态，再用 15 秒的页面断言验证自动刷新。其它后台任务状态断言采用相同等待预算；没有修改生产轮询周期或用点击刷新替代自动更新。

新增两种密码环境的回归：空密码、与测试不同的密码；均核对两个登录入口、错误密码拒绝和夹具退出后的配置恢复。第一次新增回归与其它测试共享登录配额，收到 429；该凭据回归单独禁用限流，限流行为继续由专项测试验证。
