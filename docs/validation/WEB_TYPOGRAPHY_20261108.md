# Web 字体与界面细节优化（2026-11-08）

延续橙色校园风格，参考本地设计资料与已有组件，完成字体、文字层级、输入控件、详情及评论体验优化。全部写入和验收在本地进行，使用临时 SQLite 与附件目录；未迁移业务库、部署、改动识别默认策略或采集新图片。

## 设计来源与改动

- 本地 UI UX Pro Max 的中文可读性资料推荐 Noto Sans SC 同时承担标题和正文。采用本地已有、相同版本的 Noto Sans CJK SC 2.004 的 Regular / Medium / Bold，统一中文和英文的排版。内部子集名为 `Campus Sans SC`，使用真实 400 / 500 / 700 字重。
- 参考本地 Magic Resume 的按钮、输入框的边界、悬停、聚焦和禁用状态；没有复制该项目组件代码，也没有引入新的 UI 库。字体有独立的 SIL OFL 1.1 许可，保留官方许可原文、原文件哈希和转换记录，见 [字体来源](../../cat-frontend/public/fonts/SOURCES.md) 与 [OFL](../../cat-frontend/public/fonts/OFL.txt)。
- 统一 `ui-title`、`ui-section-title`、`ui-body`、`ui-meta`：主标题 24px、章节 18px、正文 16px、辅助信息 14px，使用 rem 支持文字放大；常规按钮使用 Medium，标题使用 Bold。原页面在本机主要使用 Microsoft YaHei，并非衬线字体回退错误。
- 按钮和输入框采用 12px 圆角，保留至少 44px 点击区域。统一输入提示、聚焦边框、禁用和错误状态；折叠说明使用原生 summary 的键盘行为与统一箭头。保留减少动态效果设置。
- 猫咪详情以猫名作为唯一一级标题，减少重复页面标题；故事和资料的文字节奏一致。200% 文本检查修复桌面导航按钮被 flex 压矮，以及返回按钮随 rem 放大、网格列仍固定 44px 导致的标题重叠。
- 帖子正文与评论输入更易读，图片可打开现有大图查看器。评论区区分初次失败、刷新失败和空内容，发送失败保留草稿；同步锁防止进行中重复提交，旧读取结果不会盖掉新回复。点赞、采纳和删除失败保留明确反馈。删除弹窗支持键盘操作并修复父容器间距导致的偏移。

## 字体交付

字体完全自托管，`font-display: swap` 允许加载期间使用系统字体显示文字；不依赖外部字体服务。Unicode 范围不重叠，按页面实际出现的字符和字重请求分片。

| 项目 | 结果 |
|---|---|
| 三个核心片 | 合计 464,032 B，约 453.2 KiB；每字重覆盖 911 个码位，包括生成时源码中的 770 个汉字 |
| 扩展片 | 每字重 28 片，每片最多 256 字符，最大 73,724 B，约 72.0 KiB |
| 全部 WOFF2 | 87 个文件，4,909,128 B，约 4.68 MiB；每字重覆盖完整 GB2312 |
| 示例首页加载 | 数据加载后实测 11 个字体请求，890,804 B，约 870 KiB；包含动态猫名和地点触发的扩展片 |
| 全部字体目录 | 5,215,268 B，包括 CSS、清单与许可文档；不是每次访问的下载量 |

上述字节数是本地 Chromium 的固定示例测量，不代表所有用户内容、校园弱网加载时间或真机表现。文件名包含内容哈希，缓存期限仍由目标静态服务器决定。没有对全套字体预加载；源字体不包含的 Emoji、罕见字符继续使用系统回退。

[重建脚本](../../scripts/build_web_fonts.py) 读取已有 OFL 字体，不修改源文件、不下载字体、不删除旧资产。构建依赖放在独立工具环境，不加入前端运行依赖。更新文案后可重建核心字符集，并审查清单变化。
