# 保守确认策略：校准与留出验收

日期：2026-11-01。基线 `a4ae02c`。本记录先于本轮模型查询建立，现已补齐结果。**候选策略降低了未知猫误确认，但留出集已知猫正确确认率 77.78% 未达到 80%，本轮整体验收失败。** 工程门禁通过，候选保持实验状态，VER-001 未关闭。

## 预先固定的目标和规则

用户选择的临时业务目标为：**未知猫误确认率 ≤5%，已知猫正确确认率 ≥80%**。另设置已知猫错误确认率 ≤5%、无猫误确认率 ≤5%、不可用数为 0 的检查。这些是本批样本的经验通过线，不是校园流量或总体错误率的统计保证。

[协议](recognition-calibration-protocol.json)固定 8 个确认阈值 × 4 个前两名分差，共 32 个候选；待确认阈值保持 0.49。只在校准集上选择，先满足全部目标，再按正确确认数、误确认数及协议所列规则排序。无可行方案则不打开测试集；有可行方案则先将选定策略及证据哈希提交到 Git，再执行留出测试。测试失败时保留失败，不用测试集重新调参。

## 数据与来源

- [校准清单](recognition-calibration-manifest.json)和[测试清单](recognition-holdout-manifest.json)共享同一组 24 个已知身份、每个 2 张参考图，共 48 张参考图。两组已知查询身份各 12 个，未知查询身份各 20 个，查询身份无交叉；测试身份的参考图属于预先固定的图库。
- 每组查询包含已知猫 36 张、未知猫 60 张、狗脸 20 张，共 116 张。两组连同共享参考图共 280 张唯一图片。猫身份和图片均排除上一轮公开预评测所用身份/图像；两组查询与参考图无精确或像素重复，dHash 距离 ≤4 的候选为 0。
- 猫照片沿用 [Cat Individual Images v1](https://www.kaggle.com/datasets/timost1234/cat-individuals)，Tzu-Yuan Lin / timost1234，发布许可 CC BY 4.0。来源目录缺少拍摄场次信息；身份来自提供者标签，未得到饲养者确认。
- 狗照片来自 [AFHQ 的 Kaggle v1 镜像](https://www.kaggle.com/datasets/andrewmvd/animal-faces)，原始研究为 Choi 等人的 *StarGAN v2: Diverse Image Synthesis for Multiple Domains*（CVPR 2020）。[NAVER 原始许可说明](https://github.com/clovaai/stargan-v2/blob/875b70a150609e8a678ed8482562e7074cdce7e5/README.md#license)与镜像均标为 CC BY-NC 4.0，本次仅作非商业研究评测。原图未经编辑；模型预处理和仅供本机复核的联系表会缩放/裁剪图片。仓库和 CI 产物不分发照片。
- [视觉排除记录](recognition-calibration-visual-exclusions.json)登记多猫无目标框、疑似跨目录身份混杂等原因；先检查 280 张初选图，再按固定备用顺序替换并复核。原始联系表、替换表与哈希见[复核记录](recognition-calibration-visual-review.json)。没有根据模型分数删图。

本次划分隔离的是查询身份。参考图和同身份查询仍可能来自同次拍摄；许多姿态和背景相似。狗图没有个体身份/场次标注，也可能存在相关样本。模型训练清单仍缺失，训练重叠未知。玩具猫、屏幕猫、多猫照片和校园真实上传分布不在本轮负样本覆盖范围内。

## 实现与工具检查

实际识别与离线重算共用 `RecognitionPolicy`。确认可要求“最高相似度达到阈值，且领先第二个不同猫身份达到最低分差”；正分差策略在只有一个参考身份时返回待确认，不把缺少竞争对象当作可靠分离。默认确认阈值 0.57、待确认阈值 0.49、分差 0，初始提交未改变业务默认判定。

配置、健康检查与 Compose 传递 `RECOGNIZE_MIN_MARGIN`。拒绝非有限、越界或顺序错误的参数；HTTP 识别返回字段保持不变。评测记录额外保存分差和共享策略源码哈希。

`calibrate_recognition.py` 检查分区、完整图库、身份/图像泄漏、真实预测数量、图像哈希及固定模型。选择阶段拒绝测试集结果；测试阶段核对冻结策略、清单、模型、预处理以及实际推理参数，并逐图比对线上策略与离线重算。输出逐组指标、失败身份集中情况及带独立性限制说明的区间。

初版完整后端回归 **271 passed / 68 warnings / 177.07 秒**，见[全量日志](recognition-calibration-backend-local.log)；补充健康检查、固定模型约束与实际识别分差合同后，定向 **60 passed / 16 warnings**，见[定向日志](recognition-calibration-focused.log)。[分区校验](recognition-calibration-boundaries.json)确认 280 张唯一图片、24 个参考身份和各 116 张查询。

补查发现健康响应的 Pydantic 模型会过滤新增分差字段；[序列化回归先失败](recognition-calibration-health-before.log)，补齐 API 模型和前端类型后[19 项通过](recognition-calibration-health-after.log)，前端类型检查也通过。此处只给健康响应增加 `minimum_margin`，识别响应字段不变。

模型、协议、清单和校准代码在 `c972a99` 冻结并推送，随后启动[校准运行 41301115350](https://github.com/54123-phoenix/cat-cat-cat/actions/runs/41301115350)。该提交的[七项常规 CI](https://github.com/54123-phoenix/cat-cat-cat/actions/runs/41301114160)全部成功，见[摘要](recognition-calibration-ci-first-summary.json)。

校准真实推理完整完成 116 张查询，[运行状态](recognition-calibration-run.json)、[逐图结果](recognition-calibration-ci.json)、[48 张参考图的构建任务](recognition-calibration-build.json)与[日志](recognition-calibration-inference.log)已保存。32 个预先固定候选中有 5 个满足全部校准目标；按既定排序选中 **confirmed=0.65、uncertain=0.49、minimum_margin=0.15**。本机离线重算全部 32 个候选，与远端选择结果完全一致。

三个未知猫误确认全部集中于身份 0283；按来源标签仍计为三个错误，不因分数高或看起来相似而改标签。已知猫 0383 的一张查询因分差不足变为待确认，0352 的一张因最高分低于 0.65 变为待确认。协议优先在误确认约束内保留更多正确确认，因此没有在看到校准结果后改用另一套排序标准。

## 失败定位与适用范围

[逐图诊断](recognition-holdout-diagnosis.json)按“先看第一名是否正确，再看绝对分数，最后看分差”的顺序归类，避免重复计数：

- 3 张已知猫第一名错误，均属于 0502；其中一张真值未进入已记录的前 5 名。仅放宽确认条件不能纠正这些检索错误。
- 2 张第一名正确但最高分低于 0.65；3 张第一名正确、达到绝对阈值但分差不足。0404-4 的分差为 0.149862，按冻结的 0.15 边界保留待确认，仍计入未正确确认。
- 2 张未知猫误确认均属于 0102，被归为已入库的 0395，分差约 0.194 / 0.196。较大的前两名分差仍可能对应错误身份。

即使暂把图片当作独立试验，未知猫 2/60 的 Wilson 95% 区间约为 **0.92%—11.36%**；狗图 0/20 的区间约为 **0%—16.11%**。同一猫的多张照片、未知拍摄场次及狗身份缺失进一步限制统计解释。本轮不能证明总体误确认率 ≤5%，也不能证明校园或跨场景泛化能力。

校准与留出分别在独立 Linux CPU 容器中执行真实模型；首次查询 3.70 / 4.20 秒，后续串行 p50 为 2.08 / 2.40 秒、p95 为 2.18 / 2.62 秒。包含参考库校验，不含 HTTP，未拆分阶段耗时，不作为容量或性能改善结论。本机复算的是策略选择与证据哈希，本轮没有另做一遍本机模型推理。
