## 可复用工具与存储限制

- `scripts/MeowzartCapture.cs`：.NET Framework 响应脱敏模块，使用标准 JSON 解析器；只投影需要的猫档案字段。源码以 `csc /target:library /reference:System.Web.Extensions.dll` 编译。
- `scripts/meowzart_fiddler_capture.js`：临时 Fiddler 回调片段；替换 DLL 和输出目录占位符后放入 Handlers，通过 `OnBeforeRequest` / `OnBeforeResponse` 调用。其他域名 CONNECT 设置不解密、其他业务路径不记录。使用前备份自己的规则，结束后恢复。
- `scripts/archive_meowzart_capture.py`：校验连续分页、重复 ID、来源范围和图片地址，生成目录与哈希清单。下载默认最多 100 张、图片目录约 50 MiB，顺序下载；打包可能再使用相当大小的空间。图片保留来源水印，不上传至 Git 历史。

```powershell
python scripts/archive_meowzart_capture.py --captures <脱敏响应目录> --output <输出目录>
# 仅需要小批量图片时追加，按机器容量设置更小的上限：
python scripts/archive_meowzart_capture.py --captures <脱敏响应目录> --output <输出目录> --download --max-images 50 --max-image-mib 25
python -m pytest scripts/test_archive_meowzart_capture.py -q
```

本次验证：独立 .NET 编译通过，合成数据验证物种/社团过滤、私有字段排除、坏 JSON 与错误响应处理；10 项 Python 定向测试通过，覆盖漏页、重复 ID、页内容变动、过滤条件、外部图片域名、跨社团、缓存哈希损坏和存储预算中止。真实 37 页与 94 张图片另行通过数据检查。没有为了采集再运行全量模型或 Docker 测试。
