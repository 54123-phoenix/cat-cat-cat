## 批量读取与资料边界

检查客户端用于显示这些页面的接口合同后，对生产域名作了匿名只读验证：普通宠物列表，以及按 `societyId=1`、20 条分页、与界面一致的目录请求，均返回 HTTP 401 / errno 40304，要求微信登录。公开社团目录可以匿名读取。没有提取微信会话凭据，也没有尝试绕过接口的登录要求。

## 可重复运行的目录采集入口

新增 `cat-backend/scripts/fetch_meowzart_catalog.py`：仅向生产域名发送名单和详情 GET，固定 `societyId=1`、每页 20 条、每秒最多一次请求。只保留猫名、原站 ID、物种和照片 URL，不导入业务数据库，不保存作者或联系信息。物种不明、跨社团、分页重复、异常返回格式、登录失败或页数上限均中止；`--resume` 从第一页重新枚举，复用哈希校验通过的详情文件。续跑仍可能混合不同时刻的档案，须另做一致性复查。

该入口当前**仅采集名字与图片地址索引，不下载图片或动态照片**。它不把目录读完标记为全量重抓完成，也不自动处理图片地址、抹去水印或猜测缺失身份。API 合同来自客户端，尚未用成功的认证请求确认全部详情字段。

```powershell
# 在 cat-backend 目录执行；凭据由用户或平台明确提供，勿放入 Git。
python scripts/fetch_meowzart_catalog.py --token-file <凭据文件路径> --output ../artifacts/meowzart/catalog --resume
```

也可通过 `MEOWZART_TOKEN` 环境变量传入。14 项合成接口测试通过，覆盖同名不同 ID、非猫排除、跨社团拒绝、分页异常、失效登录、凭据不随重定向发送、断点及哈希损坏。随后真实执行一次列表请求，退出码 3、`status=authentication_required`、0 条档案、0 张脚本下载图片；没有发生认证成功的批量采集。机器记录中单独保存了这次运行状态。

主动请求脚本仍缺可用的官方接口凭据，也可以通过带导出功能的猫协登录状态取得文件。随后用户提供 `wnma3mz/wechat_articles_spider`；[源码与离线检查](WECHAT_ARTICLES_SPIDER_REVIEW_20261101.md)补充了另一条待验证路径：在小程序正常浏览时，经范围受限的调试代理直接采集目标响应正文中的猫名与图片地址，无需先为脚本取得会话令牌。当前尚未验证微信小程序的代理兼容性或成功取得该类响应。无需再找旧导出文件；接通后先核对目录与图片关系，再分块下载和远端备份，并校验完整清单。
